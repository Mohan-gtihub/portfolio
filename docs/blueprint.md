# **App Name**: Kilari Tech Solutions

## Core Features:

- Interactive 3D Hero Section: Animated 3D circuit boards and microcontrollers for an engaging introduction.
- Project Showcase: Grid layout with images, GIFs, and videos of embedded and web development projects.
- Skills Visualization: Animated progress bars and interactive badges for skills in embedded systems and web development.
- Contact Form: Modern contact form with links to LinkedIn, GitHub, and other professional profiles.
- Dark/Light Mode Toggle: User-selectable dark/light mode for optimal viewing experience.
- IoT Demo Section: AI-powered live visualization of sensor readings, LED control, and cloud data from IoT devices. An LLM tool will automatically use contextual clues (time of day, recent usage) to vary demo parameters.
- Performance Monitoring: Automatic data capture and live performance stats from demonstrated websites

## Style Guidelines:

- Primary color: Deep blue (#4682B4) to convey professionalism and a high-tech feel.
- Background color: Very dark gray (#222222) to enhance the futuristic dark mode aesthetic.
- Accent color: Electric purple (#8A2BE2) for highlights and interactive elements to add a vibrant, modern touch.
- Font: 'Inter' (sans-serif) for both headlines and body text. This provides a clean, modern, and readable look, suitable for a professional portfolio.
- Use sleek, minimalist icons relevant to embedded systems, IoT, and web development to maintain a consistent, professional visual style.
- Implement a clean, structured layout with clear sections and smooth transitions for enhanced user experience and intuitive navigation.
- Subtle animations for section transitions, statistics display, and hover effects to add interactivity and visual appeal.
